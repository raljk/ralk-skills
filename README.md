# Ralk Skills

Three reusable skills for presentation reviews, design thinking, and written communication.

## Skills

- [Deck Playback Review](plugins/deck-playback-review/skills/deck-playback-review/SKILL.md): review a presentation and develop a clearer, audience-focused outline.
- [Design Thinking](plugins/design-thinking/skills/design-thinking/SKILL.md): choose an approach using frameworks, playbooks, proposal templates, and guidance for sourcing case studies.
- [Ralkify Tone](plugins/ralkify-tone/skills/ralkify-tone/SKILL.md): apply a conversational, professional tone using Australian English.

## Structure and use

Each folder under `plugins/` retains its original `.claude-plugin/plugin.json` manifest and `skills/` structure. Read the relevant `SKILL.md` for its workflow. Keep the Design Thinking `references/` folder beside its `SKILL.md`.

For a skill-based assistant, copy the selected skill directory into that assistant's supported skills location. Plugin installation steps depend on the host application.

This public edition omits client-specific case studies, proposal examples, pricing, and prototype access details. It replaces one personal example with a neutral project example. Generic workflows and reference structures are retained. No new licence is granted by this repository.
